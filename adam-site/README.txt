ADAM website
============
Open index.html in a browser to view the site (no server needed).

Where to edit
- js/data.js    Text, menu links, sponsors, parts, design log, team, email. Start here.
- css/style.css Colors (top of file), fonts and layout.
- js/main.js    Shared behavior (menu, sponsor banner, animations).
- *.html        Page structure. Each page has its own file.
- images/       Put logos, team photos and pictures here.

Add a page: copy contact.html, rename it, change the content, then add an entry to NAV in js/data.js.
Add a sponsor: add a line to SPONSORS in js/data.js (optionally with a logo image path).
